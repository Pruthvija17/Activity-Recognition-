# BAS Activity Intelligence

## Brand & Visual Design System

---

# 1. Brand Identity

**Brand Name:** BAS Activity Intelligence

**Short Name:** BAS AI

**Product Category:** AI-powered experiment monitoring and activity intelligence

**SIH Problem Statement:** SIH26174

### Tagline

> **Observe. Understand. Record.**

### Descriptor

> **AI-powered activity intelligence for BAS experiments.**

### Alternative positioning line

> **Turn experiment video into structured experimental evidence.**

---

# 2. Brand Concept

BAS Activity Intelligence combines:

* aerospace experimentation
* computer vision
* artificial intelligence
* human activity understanding
* experiment monitoring
* scientific data logging

The visual identity should communicate:

**Precision + Intelligence + Trust + Scientific Clarity**

It should feel like a serious research/mission-control product rather than a generic AI startup.

---

# 3. Visual Direction

## Primary visual concept

**Light blue + white**

The interface should feel:

* clean
* scientific
* modern
* trustworthy
* technical
* calm
* aerospace-inspired

Avoid an overly dark "sci-fi AI" aesthetic.

The product should resemble a modern scientific monitoring platform.

# 6. Logo Direction

The logo should combine:

* a subtle astronaut/experiment reference
* camera/vision concept
* AI/data signal
* circular tracking/observation motif

Avoid an overly literal astronaut illustration.

A preferred concept:

> **A simplified circular observation lens containing an abstract human figure or activity trajectory.**

Possible logo symbol:

```text
      ◌
   ╭─────╮
   │  ◇  │
   │ /|\ │
   │ / \ │
   ╰─────╯
```

The final logo should remain recognizable at small sizes.

---

# 7. UI Style

Use:

* white cards
* subtle blue borders
* soft shadows
* 12–16px corner radius
* clean spacing
* compact data visualizations
* thin line icons
* restrained animations

Avoid:

* excessive gradients
* glassmorphism everywhere
* neon colors
* excessive glowing effects
* cluttered dashboards

# 27. Design Principles

## 1. Scientific Clarity

Every visualization should communicate useful information.

## 2. Operator First

Critical information must be visible immediately.

## 3. Trust Through Transparency

Always show confidence and review status.

## 4. Human-in-the-Loop

AI assists the operator rather than replacing human judgment.

## 5. Minimal Complexity

Advanced AI should appear simple from the user's perspective.

## 6. Evidence Over Hype

The interface should communicate actual detected evidence rather than exaggerated AI claims.

---

# 28. Responsive Design

The platform should support:

* desktop
* laptop
* tablet

Desktop is the primary target because experiment monitoring dashboards require large video and timeline areas.

Mobile should provide:

* alerts
* experiment status
* activity summaries
* review notifications

Full live video analysis is not the primary mobile use case.

---

# 29. Accessibility

The interface should support:

* readable contrast
* keyboard navigation
* clear status labels
* icons accompanied by text
* non-color-only status indicators
* accessible buttons
* readable tables

---

# 30. Brand Experience

The user should feel:

> “This is a generic AI dashboard.”
